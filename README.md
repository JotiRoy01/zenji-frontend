# ZENJI — Frontend Assessment

A polished, frontend-only storefront inspired by the visual language and information architecture of ZENJI: anime-inspired streetwear, limited drops, editorial storytelling, product discovery, and a technical/cyberpunk UI layer.

## Stack

- React 18
- Vite
- JavaScript
- CSS
- Lucide React

## Features

- Responsive homepage with hero, Origin collection, latest drops, manifesto, lookbook teaser, and newsletter
- Collection filtering
- Product quick-view modal
- Size selection
- Local shopping bag with quantity controls
- Wishlist state
- Search overlay
- Lookbook filtering
- Drop page with live countdown
- Waitlist feedback state
- Story / brand page
- Responsive mobile navigation
- Reduced-motion accessibility support
- Image lazy-loading friendly architecture

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

This is intentionally frontend-only. No backend, database, authentication, checkout API, or payment processing is included, matching the assessment brief.

The imagery uses Unsplash-hosted editorial photography and CSS-generated product graphics so the visual system can be demonstrated without copying anime IP or ZENJI source assets.
